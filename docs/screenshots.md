# Screenshots

Images used in the README live in `docs/images/`. They are referenced by absolute
`raw.githubusercontent.com` URLs so they also show on PyPI.

| File | Shows | Status |
|---|---|---|
| `menu-convert-to.png` | The **Convert to** submenu on a `.md` file | Done |
| `menu-to-markdown.png` | **Convert to Markdown** on a PowerPoint file | Done |
| `hotkey-menu.png` | The Ctrl+Alt+M menu for a Markdown file | Done |
| `hotkey-to-markdown.png` | The Ctrl+Alt+M menu for any other file | Done |
| `before-after.png` | A Markdown file beside the Word document it produced | Optional |
| `excel-output.png` | The Excel output: one sheet per table, numbers formatted | Optional |
| `demo.gif` | 10–15 seconds: right-click → Convert to → Word → popup → open the result (under 5 MB) | Optional |

Tips for new screenshots:
- Use example files, so no real documents or names appear.
- Hide anything personal: your user name in the address bar, other files in the folder, the taskbar.
- Use the same Windows theme for all of them (the current set is dark).
- Crop tightly to the menu or window; about 800–1200 px wide reads well on GitHub.
